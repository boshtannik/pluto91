# Инструкция пользователя

**Pluto** — наручные часы в стиле Casio F-91W. Управление — тремя кнопками:

| Кнопка  | Эмулятор (клавиатура) |
|---------|------------------------|
| Light   | `W` (или ↑)            |
| Mode    | `S` (или ↓)            |
| Alarm   | `D` (или →)            |

В эмуляторе кнопки также можно нажимать мышью на корпусе часов на странице.

---

## Кнопки и жесты

| Жест           | Что это                                              |
|----------------|------------------------------------------------------|
| **Нажатие**    | короткий тап — действие происходит **на отпускание** |
| **Двойное**    | два тапа подряд в пределах 0,4 с                     |
| **Удержание**  | держать > 0,75 с; при удержании повтор происходит автоматически каждые 0,25 с |
| **Аккорд**     | две кнопки нажаты одновременно                       |

---

## Фейсы (режимы)

В часах три фейса — **«Часы»**, **«Будильник»** и **«Простой будильник»**.
Короткое нажатие **Mode** переключает между ними. Состояние каждого фейса
сохраняется при переключении: настройки будильника не теряются, когда вы
уходите на «Часы» и возвращаетесь обратно.

> Какие фейсы есть в конкретной сборке, задаётся в
> `crates/pluto-faces/faces.toml` — фейса, которого нет в списке, нет ни в
> прошивке, ни в эмуляторе (в сборке по умолчанию — **«Часы»** и
> **«Простой будильник»**).

---

## Фейс «Часы» (SimpleClock)

Показывает время и дату:

```
 дн-недели  число      ЧЧ:ММ:СС
 SU, MO, …  1..31     час без ведущего нуля
```

Индикаторы:

| Индикатор | Значение                                     |
|-----------|----------------------------------------------|
| **H24**   | включён 24-часовой формат                    |
| **PM**    | 12-часовой формат, время после полудня       |
| **SIG**   | включён почасовой сигнал                     |

Управление:

- **Alarm** — короткий писк и переключение **12/24-часового формата**
  (индикатор H24).
- **Light + удержание** — подсветка на ~3 секунды (выключается сама).
- **Mode** — перейти к следующему фейсу.

---

## Фейс «Будильник» (Alarm)

Один будильник на каждый день недели (вс…сб). У будильника настраиваются:
день недели, часы, минуты и состояние (вкл/выкл).

### Просмотр

```
 AL   число        ЧЧ:ММ
      активных      текущее время (живые часы)
      будильников
```

- Буквы **AL** — это фейс будильника.
- В правом верхнем разряде — **сколько будильников включено**.
- Индикатор **Bell** горит, если включён хотя бы один будильник.

Управление в режиме просмотра:

- **Alarm** — переключение **почасового сигнала** (индикатор SIG).
- **Light** — войти в настройку будильника.
- **Mode** — перейти к следующему фейсу.

### Настройка

Короткое нажатие **Light** в режиме просмотра включает режим настройки.
Поля переключаются в порядке: **день → часы → минуты → вкл/выкл**.
Выбранное поле **мигает**.

В режиме настройки на дисплее показывается, какое поле редактируется:

| Буквы | Поле            |
|-------|-----------------|
| дни недели | день будильника (вс…сб) |
| `HO`  | часы            |
| `MI`  | минуты          |
| `AC`  | вкл/выкл        |

Состояние вкл/выкл показывается буквами **ON / OF** в разрядах секунд.

| Действие           | Результат                                        |
|--------------------|--------------------------------------------------|
| **Light**          | перейти к следующему полю; на поле «вкл/выкл» — выйти из настройки |
| **Light + удержание** | выйти из настройки (в любой момент)           |
| **Alarm**          | увеличить значение на 1                         |
| **Alarm + двойное**| увеличить значение на 5                         |
| **Alarm + удержание** | сбросить значение в 0 (день — вс, часы/минуты — 00) |
| **Alarm + Light**  | установить будильник на **текущее время**       |

Полезные мелочи:

- При входе в настройку **ещё не настроенный** будильник (выключенный,
  время 00:00) автоматически заполняется **текущим временем** — удобно,
  если нужно «через несколько минут».
- Во время быстрой прокрутки (удержание) значение показывается не мигая,
  чтобы было легче читать; мигание возвращается сразу после остановки.

### Срабатывание

Когда наступает время включённого будильника, часы **сами переключаются на
фейс «Будильник»** (откуда бы вы ни смотрели) и подают сигнал. Звон
длится до **2 минут** либо пока вы не нажмёте любую кнопку. Если вы
переключите фейс кнопкой Mode, звон тоже прекратится.

Пока будильник звонит, фейс показывает **текущее время полностью**
(с секундами), а **индикатор Bell мигает** раз в полсекунды.

## Фейс «Простой будильник» (SimpleAlarm)

Классический будильник в стиле Casio — один на всё, без дней недели.

### Просмотр

```
 AL          ЧЧ:ММ
             время будильника
```

- Буквы **AL** — это фейс будильника.
- Время будильника показывается в текущем 12/24-часовом формате, без
  ведущего нуля (секунды не показываются).
- Индикатор **Bell** горит, если будильник включён.

Управление в режиме просмотра:

- **Alarm** — включить/выключить будильник (индикатор Bell).
- **Light** — войти в настройку.
- **Mode** — перейти к следующему фейсу.

### Настройка

Короткое нажатие **Light** в режиме просмотра включает режим настройки.
Поля переключаются в порядке: **часы → минуты**. Выбранное поле **мигает**;
на дисплее видно, какое поле редактируется — `HO` (часы) или `MI` (минуты).

| Действие              | Результат                                      |
|-----------------------|------------------------------------------------|
| **Light**             | перейти к следующему полю; на минутах — выйти из настройки |
| **Light + удержание** | выйти из настройки (в любой момент)            |
| **Alarm**             | увеличить значение на 1                        |
| **Alarm + двойное**   | увеличить значение на 5                        |
| **Alarm + удержание** | сбросить значение в 0                          |
| **Alarm + Light**     | установить будильник на **текущее время**      |

Полезные мелочи:

- При входе в настройку **ещё не настроенный** будильник (выключенный,
  время 00:00) автоматически заполняется **текущим временем** — удобно,
  если нужно «через несколько минут».
- Аккорд **Alarm + Light** в любой момент заново выставляет будильник на
  текущее время; в режиме просмотра он также сразу открывает настройку,
  чтобы подправить время.
- Во время быстрой прокрутки (удержание) значение показывается не мигая,
  чтобы было легче читать; мигание возвращается сразу после остановки.

### Срабатывание

Как и у основного будильника: когда наступает время, часы **сами
переключаются на этот фейс** и подают сигнал до **2 минут** либо пока вы не
нажмёте любую кнопку. Звон начинается ровно в начале минуты (ЧЧ:ММ:00),
поэтому только что установленный будильник не звонит в середине минуты.

Пока будильник звонит, фейс показывает **текущее время полностью**
(с секундами), а **индикатор Bell мигает** раз в полсекунды; как только звон
закончился — снова время будильника.

---

## Почасовой сигнал (chime)

В начале каждого часа часы коротко пищат, если включён почасовой сигнал
(индикатор **SIG**). Включается и выключается кнопкой **Alarm** на фейсе
«Будильник» (в режиме просмотра); индикатор SIG виден и на фейсе «Часы».
